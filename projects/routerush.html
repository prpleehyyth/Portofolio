Role

Stack

Overview

A mobile application that optimizes multi-stop delivery routes using machine learning, built with a multidisciplinary Agile team spanning mobile development, machine learning, and cloud computing cohorts during Bangkit Academy.

The challenge

  • Delivery drivers with multiple stops needed a way to sequence routes efficiently to save time and fuel.
  • The mobile app needed a reliable, scalable backend to serve ML-driven route recommendations.

The approach

  • Designed and built RESTful APIs in Node.js to connect the mobile app with Google Cloud services and the ML inference service.
  • Deployed containerized backend services on Google Cloud Run for scalable, serverless hosting.
  • Set up a CI/CD pipeline with Google Cloud Build to automate image builds and deployments.
  • Integrated Cloud SQL, Cloud Storage, and Artifact Registry to support the backend infrastructure.

The result

  • A working end-to-end pipeline from mobile app to ML inference to optimized route output.
  • Serverless deployment that scales automatically with demand.
  • Automated deployments that removed manual release steps for the team.
